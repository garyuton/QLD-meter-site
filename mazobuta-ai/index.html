最近よく出る名前の置き場

新しい名前に出会ったら、ここに足していく早見表です。まず「どの層の話か」を決めれば、疲れません。

  1. Q1 頭脳(モデル)?GPT、Claude、Gemini、H3 など「考える部分」の名前なら3層目。
  2. Q2 人が触る入口?アプリ、IDE、チャット画面なら2層目の製品。
  3. Q3 AIが操作する道具?ファイル、ブラウザ、GitHubなら4層目の手足。

DeepSeek / Mistral / Qwen

1 会社 / 3 モデル

大手5社以外の、モデルを作る会社・チーム

DeepSeek(中国)、Mistral(フランス)、Qwen(Alibaba)など。重みを公開するモデルが多く、自分のPCやfalのような置き場でも動かせます。

仲間:Llama(Meta)

Seedance

3 モデル(ByteDance)

ByteDance(TikTokの親会社)の、動画生成モデル

会社がモデルも製品も自前で持つタイプ。入口はCapCut、Jimeng AI、DoubaoのPro版など。最新は2026年7月のSeedance 2.5です。

対比:H3 Max Turbo(他社モデルをfalが加工して出す)

Veo / Kling / HappyHorse

3 モデル

動画生成モデルの、ほかの有力どころ

Veo=Google、Kling=Kuaishou(快手)、HappyHorse=Alibaba。順位の入れ替わりが速いので、優劣は決めつけないのがコツです。

仲間:Seedance / H3 Max Turbo

FLUX / Stable Diffusion

3 モデル

画像生成の、オープン系の代表モデル

FLUX=Black Forest Labs、Stable Diffusion=Stability AI。falのような置き場や、自分のPCでも動かせます。

仲間:fal / Hugging Face

H3 Max Turbo

3 モデル

文章や画像から動画を作る、動画生成モデル

元はMiniMaxのオープンなH3で、falが手を入れた“速い版”。出どころの説明は情報源で差があります。

流れ:MiniMax(H3)→ fal(Max / Turbo)→ Krea・Picsart

ChatGPT dots

2 製品(エージェント型)

OpenAIの、ChatGPTの中で動く“常時稼働”のAIエージェント

頭脳=GPT-6 Astra、手足=専用のクラウドPCと4,000超のアプリ、実行ループ=会話が終わっても続く作業。エージェントの図そのままの製品です。2026年9月29日発表(ProとBusiness Premium向け)。

対比:ChatGPT(質問に答える会話型)

Antigravity

2 製品

Googleの、AIエージェント向けの開発環境(IDE)

エディタ・ターミナル・ブラウザをAIが動かして、計画から確認まで進める入口。頭脳はGemini中心で、他社モデルも選べる仕様です。

仲間:Cursor / GitHub Copilot / Claude Code / Codex

Cursor

2 製品

AI中心で作られたコードエディタ(VS Codeの派生)

複数社のモデルから選べて、独自モデルも持っています。エディタの中でAIが複数のファイルをまとめて直します。

仲間:Antigravity / Claude Code / Codex

Copilot(2種類)

2 製品(同名)

「Copilot」は別物が2つあります

GitHub Copilot=コード補助のAI。Microsoft Copilot=WindowsやOfficeに入った対話アシスタント。どちらもMicrosoft系ですが、入口が違います。

注意:Claude・Gemini・Grok と同じ“名前かぶり”

AIエージェントとは?

モデル(脳)考える。文章や判断を出す
+
ツール(手足)調べる・書く・動かすための道具
+
実行ループ計画 → 実行 → 確認 → やり直し

単なる会話AIではなく、調べる・書く・実行する・直す、まで進める仕組み

会話AI

例:「このエラーの意味は?」

質問→答える

1回答えたら終わり。実行や修正はあなたがやる。

AIエージェント

例:「テストが落ちるバグを直して」

調べる→書き直す→テスト実行→まだ失敗?
直るまで くり返す

お店でたとえると

会社
メーカー(作っている人たち)
製品
使う場所(お店やお客さん向けの窓口)
モデル
頭脳(考える腕前)
ツール
手足(道具・作業台)
エージェント
頭脳と手足を使って、仕事を最後までやり切る人
「Claude」はチャット画面のことClaudeは製品名であり、頭脳(モデル)の名前でもあります。画面と中身は別に考えます。
Claude Code は別のAI開発者向けの製品です。中の頭脳はClaudeモデルで、ファイルやコマンドを扱う“手足”が付いています。
頭脳が新しくなったら別の製品になる製品名は同じまま、中のモデルが入れ替わることが普通です。ChatGPTも、GPT-4oの時代からGPT-6系へ中身が変わりました。

超要約

  1. 1Anthropic は Claude を作っている会社
  2. 2Opus / Sonnet / Haiku は Claude のモデル名(上に Mythos級 も)
  3. 3ChatGPT / Claude Code / Codex は、AIを使うための製品・実行環境
  4. 4エージェント = モデル + ツール + 実行ループ

モデル名や製品名は入れ替わりが早いので、迷ったら「会社 → 製品 → モデル → ツール」の順に、どの層の話かを当てはめてみてください。
